# V1 — Visual pass

Brought forward from M6 (D-033): a forest that looks semi-realistic for the
demo, before M2 (seasonal foliage colors depend on the final tree assets).
Gameplay does not change.

Rules:
- Third-party assets (Fab / Megascans) are **not committed** (D-010): the
  repository keeps the procedural placeholders and falls back to them when a
  replacement asset is missing; the README lists the assets to download.
- Replacement meshes are mapped in *Project Settings > ShroomHunt > Vegetation >
  Mesh Overrides* (saved in `Config/DefaultGame.ini`): no code change (D-024).
- 16 GB of RAM: few species and medium texture quality first; load the
  forest region by region in the editor.

# Step V1-1 — Trees

## What the code provides
- `UVegetationSettings::MeshOverrides`: key `Fagus_Mature_0` (one variant) or
  `Fagus_Mature` (all variants of a genus and form) → a static mesh. A listed
  mesh whose asset is not in the project uses the placeholder (so a fresh clone
  of the repository still shows a forest).
- `Tools/Python/list_static_meshes.py`: lists the static meshes of a folder
  with their height, width, Nanite flag and LOD count (`Saved/MeshInventory.csv`),
  to choose which tree goes to which form. Claude runs it headless.

Palette per genus (`Data/Vegetation/Vegetation.json`): `Sapling_0..1`,
`Pole_0..1`, `Mature_0..2`, `Old_0..1`. Genera: `Fagus` (beech), `Quercus`
(oak), `Carpinus` (hornbeam), `Betula` (birch), `Alnus` (alder).

## Editor steps (you)
1. On [fab.com](https://www.fab.com), signed in with your Epic account, search
   **Megascans Trees: European Beech**, open it and click **Add to My Library**
   (free). Same for **Megascans Trees: European Hornbeam** and
   **Megascans Trees: European Black Alder**.
2. Get them into the project, **editor closed**, from the **Epic Games
   Launcher**: *Unreal Engine* > **Library** > section **Fab Library**, search
   each pack, click **Add to Project**, select **ShroomHunt** (tick **Show all
   projects** if it is not listed; if it asks for an engine version, take the
   newest offered). If a quality choice appears, take **Medium** or **High**,
   not *Raw* (RAM and disk). If the launcher only offers *Create Project*,
   stop and tell me.

   (Alternative if the pack is listed in the editor: **Window > Fab** or the
   **Fab** button of the Content Browser > *My Library* > the pack > **Add to
   Project**.)
3. Each pack is several GB: let the download finish. Then tell me **in which
   folders** of `Content/` the packs landed (e.g. `Content/Megascans/...`,
   `Content/MSPresets/...`). Do not open the editor yet if you can avoid it:
   I will list the meshes headless and fill the overrides myself.

## Claude, after the import
- Make sure the new folders are git-ignored (`Content/Fab/`, `Content/Megascans/`
  already are; packs may add `Content/MSPresets/` or similar).
- `list_static_meshes.py` on those folders, then map forest trees to
  `Mature` / `Old`, the smaller ones to `Pole`, saplings to `Sapling`, in
  `Config/DefaultGame.ini`.

## Then, in the editor (you)
1. Open `Lvl_F01_LowlandOakBeech`. **World Partition Editor** > select the
   whole map > **Load Region From Selection** (like in M1d).
2. Select the PCG volume > **Generate** (*Force Regenerate* if offered).
   The first time, Nanite and shaders for the new trees compile: wait.
3. Walk in the forest and send me screenshots: beech stands, hornbeam,
   alders along the streams, and the oak/birch placeholders still among them.

## Test checklist
- [ ] Beech, hornbeam and alder are Megascans trees; oak and birch still placeholders.
- [ ] Trunks stand on the ground (no floating, no sinking), sizes plausible.
- [ ] Mushrooms never grow inside a trunk (obstacle capsules still match).
- [ ] A clone without the Fab assets still shows the placeholder forest.
- [ ] Editor and game stay within RAM (no stutter from paging).
