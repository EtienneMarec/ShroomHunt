# V1 — Visual pass

Brought forward from M6 (D-033): a forest that looks semi-realistic for the
demo, before M2 (seasonal foliage colors depend on the final tree assets).
Gameplay does not change.

Rules:
- Third-party assets (Fab / Megascans) are **not committed** (D-010): the
  repository keeps the procedural placeholders and falls back to them when a
  replacement asset is missing; the README lists the assets to download.
- Replacement meshes are mapped in *Project Settings > ShroomHunt > Vegetation >
  Mesh Overrides* (saved in `Config/DefaultGame.ini`): no code change (D-024).
- 16 GB of RAM: few species and medium texture quality first; load the
  forest region by region in the editor.

# Step V1-1 — Trees

## What the code provides
- `UVegetationSettings::MeshOverrides`: key `Fagus_Mature_0` (one variant) or
  `Fagus_Mature` (all variants of a genus and form) → a static mesh. A listed
  mesh whose asset is not in the project uses the placeholder (so a fresh clone
  of the repository still shows a forest).
- `Tools/Python/list_static_meshes.py`: lists the static meshes of a folder
  with their height, width, Nanite flag and LOD count (`Saved/MeshInventory.csv`),
  to choose which tree goes to which form. Claude runs it headless.

Palette per genus (`Data/Vegetation/Vegetation.json`): `Sapling_0..1`,
`Pole_0..1`, `Mature_0..2`, `Old_0..1`. Genera: `Fagus` (beech), `Quercus`
(oak), `Carpinus` (hornbeam), `Betula` (birch), `Alnus` (alder).

## Editor steps (you)
1. On [fab.com](https://www.fab.com), signed in with your Epic account, search
   **Megascans Trees: European Beech**, open it and click **Add to My Library**
   (free). Same for **Megascans Trees: European Hornbeam** and
   **Megascans Trees: European Black Alder**.
2. Get them into the project, **editor closed**, from the **Epic Games
   Launcher**: *Unreal Engine* > **Library** > section **Fab Library**, search
   each pack, click **Add to Project**, select **ShroomHunt** (tick **Show all
   projects** if it is not listed; if it asks for an engine version, take the
   newest offered). If a quality choice appears, take **Medium** or **High**,
   not *Raw* (RAM and disk). If the launcher only offers *Create Project*,
   stop and tell me.

   (Alternative if the pack is listed in the editor: **Window > Fab** or the
   **Fab** button of the Content Browser > *My Library* > the pack > **Add to
   Project**.)
3. Each pack is several GB: let the download finish. Then tell me **in which
   folders** of `Content/` the packs landed (e.g. `Content/Megascans/...`,
   `Content/MSPresets/...`). Do not open the editor yet if you can avoid it:
   I will list the meshes headless and fill the overrides myself.

## Claude, after the import

## Then, in the editor (you)

2. Select the PCG volume > **Generate** (*Force Regenerate* if offered).
   The first time, Nanite and shaders for the new trees compile: wait.
3. Walk in the forest and send me screenshots: beech stands, hornbeam,
   alders along the streams, and the oak/birch placeholders still among them.

# Step V1-2 — Forest floor (prepare tonight)

A real forest floor is a continuous carpet of dead leaves, also on rides and
footpaths, with plants growing through it: this comes from the **ground
material** (the landscape layers, today flat colors), not from 3D objects.
The 3D leaves of V1-3 only add relief on top.

## Downloads (you, with the tree packs)
On fab.com, search and **Add to My Library** a few free **Megascans surfaces**
(filter *Megascans*, type *Material* / *Surface*), close to the photos:
- dry **beech leaf litter** on the forest floor (main layer: `Litter`);
- **forest moss** (layer `Moss`);
- **forest grass** with some leaves (layer `Grass`, rides);
- **mud / wet soil** with leaves (layers `Mud` and `Dirt`, ruts and banks);
- **gravel road** (layer `Gravel`).
Take 2K or 4K if a resolution is offered (not 8K: RAM). Add them to the
project like the trees, or from the editor's **Fab** window. Tell me their
names and folders: I will write the material steps (one material function per
layer, height blend so leaves fill the low spots, distance tiling to hide
repetition) and, if needed, rebake the weightmaps so leaves also fill the ride
ruts and the footpaths.

# Step V1-3 — Ground debris

Done before V1-1/V1-2 (the tree packs were still downloading): it needs no
third-party asset.

## What the code provides
- A third vegetation layer, **Ground**, with four kinds in the `Ground` list of
  `Data/Vegetation/Vegetation.json` (same fields as the understory rules, plus
  `SlopeBoost`, `BankBoost` and `PathFactor`):
  - **Leaf**: single fallen leaves placed **one by one** (no thinning, ~7 per m²
    under closed stands), one mesh set per genus (`Litter` color, `LeafSizeCm`,
    `LeafLobes` of each tree archetype: copper beech, lobed oak, yellow birch,
    brown hornbeam, dark alder; 4 variants each). The genus is drawn from the
    stand weights at the spot, so the leaves match the trees above. Also on
    rides (x0.6) and footpaths (x0.4), never on gravel roads
    (`PathFactor` [road, ride, footpath]). They add relief on top of the
    continuous leaf carpet of the ground texture (V1-2);
  - **Twigs**: dead twigs, more under old stands;
  - **Stones**: half-sunk mossy stones, more on slopes and along streams;
  - **Moss**: cushions on moist ground.
- Ground debris lies flat on the terrain slope, never in the water, skips the
  trunk test (tiny, hidden by trunks anyway) and has no collision.
- About **8 million leaves** for F01 (`sh.Vegetation.Stats` estimates them from
  1 ha): far too many to store, so this layer is **generated at runtime around
  the player** by PCG (hierarchical runtime generation, 32 m cells, ~40 m
  radius), each leaf at a deterministic position.
- Baked like the trees (`sh.Vegetation.BakeMeshes`): `SM_<Genus>_Leaf_<n>`,
  `SM_Twigs_<n>`, `SM_Stones_<n>`, `SM_Moss_<n>`; replaceable by Megascans debris
  through *Mesh Overrides* later (e.g. key `Fagus_Leaf`).
- Preview: `sh.Vegetation.ExportObj`, then
  `render_mushroom_preview.py Saved/VegetationDebug <out.png> --grid --top`.

![Ground debris placeholders](../Media/placeholder_ground_debris.png)

> **UE concept — PCG runtime generation.** A PCG component set to *Generate At
> Runtime* generates its graph only in a grid of cells around the player (the
> *generation source*) and cleans up the cells left behind, while playing.
> With *hierarchical generation* the graph runs per cell of a fixed grid size.
> Ideal for dense small detail: nothing is stored in the level.

## Editor steps (you)
1. **Remove the ground debris from the static graph.** Open
   `PCG_ForestVegetation`, delete the third **Forest Scatter** (*Layer* =
   *Ground*) and its **Static Mesh Spawner**. **Save**.
2. **Clean the old instances.** In `Lvl_F01_LowlandOakBeech`: *World Partition
   Editor* > select the whole map > **Load Region From Selection**; select the
   existing PCG volume > PCG Component > **Cleanup**, then **Generate** (trees
   and understory only now). *File > Save All*.
3. **Runtime graph.** In `Content/ShroomHunt/Forests/F01`: right-click > **PCG** >
   **PCG Graph**, name `PCG_ForestGround`, open it:
   - add **Forest Scatter** (*Layer* = *Ground*, Align To Landscape ticked) and a
     **Static Mesh Spawner** wired to it: **Mesh Selector Type** =
     `PCGMeshSelectorByAttribute`, **Attribute Name** = `Mesh`; **Template
     Descriptor**: **Collision Presets** = `NoCollision`, **Cast Shadow**
     unticked, **Instance Start Cull Distance** = `2500`, **Instance End Cull
     Distance** = `3500`;
   - click an empty area of the graph: in **Details** (graph settings) tick
     **Use Hierarchical Generation** and set **HiGen Default Grid Size** to
     `Grid3200` (32 m cells). **Save**.
4. **Runtime volume.** In the level, **Quick Add** > `PCG Volume`, same
   transform as the first one (**Location** `0, 0, 0`, **Scale** `504, 504, 40`).
   Its **PCG Component**:
   - **Graph** = `PCG_ForestGround`;
   - **Is Partitioned** = ✔;
   - **Generation Trigger** = *Generate At Runtime*;
   - in **Runtime Generation** (or *Generation Radii*): radius for the 3200
     grid = `4000` (40 m), cleanup radius a bit larger (e.g. multiplier `1.2`).
   Do **not** click Generate: it generates while playing.
   *File > Save All*.
5. **Play**: leaves, twigs, stones and moss appear around you and follow you.
   (In the editor viewport, the PCG toolbar/menu has a *Preview runtime
   generation* option if you want to see it without playing.)

If one of these property names differs in your editor, stop there and tell me
what you see.
