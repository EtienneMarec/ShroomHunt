# M2 — Seasons

Code written ahead (2026-11-23, branch `feat/night-groundwork`). Since
2026-11-25 every tree is procedural and stylized (D-039): the seasonal colors
and the leaf fall are set up once, in `M_Vegetation`.

## What the code provides

- **Leaf calendar per genus** (`Data/Vegetation/Vegetation.json`, fields
  `LeafOutMonth`, `ColoringMonths`, `LeafFallMonths`, `WinterLeaves`,
  `AutumnFoliage`): birch turns first, oak last and keeps some dead leaves
  through the winter, like young beeches.
- **`SeasonModel`** (pure, `Environment/SeasonModel`): for each genus and real
  month, the leaf amount on the tree, the autumn coloring, the light green of
  young spring leaves and the bright freshly fallen litter. Each year is a
  little early or late (deterministic, about a week).
- **`MPC_Season`** (created by `Tools/Python/create_season_collection.py`,
  already run and committed), written every frame by the Environment Director:

  | Parameter | Meaning |
  |---|---|
  | `LeafAmount`, `Coloring`, `Freshness`, `FreshLitter`, `FoliageColor` (vector) | forest averages (placeholder trees use these) |
  | `<Genus>LeafAmount`, `<Genus>Coloring`, `<Genus>Freshness`, `<Genus>FoliageColor` | per genus (Fagus, Quercus, Carpinus, Betula, Alnus): for a later per-genus material (genus id in the mesh) |
  | `SnowCover` | ground covered by snow, 0–1 |
  | `SnowFalling` | snow falling at the camera, 0–1.5 |
  | `Frost` | hoar frost on cold mornings, 0–1 |
  | `Dryness` | dry ground and grass after warm days without rain, 0–1 |
  | `Month` | continuous real month (debug) |

- **Snow** (`Weather/SnowModel`, D-035): precipitation turns to snow below
  1–3 °C (new weather state `Snow`), the snow pack is integrated from the weather
  history (nothing stored), winter cold spells bring a lowland forest
  occasional snow (about 2 % of winter hours snowing, ground white 3 % of the
  time; force it to test). The director drives a second Niagara component,
  **SnowParticles**, with user parameters `SnowIntensity` and `Wind`.
- **Winter canopy**: bare branches let most of the rain and snow through.
- **Fallen leaves** have their own surface id (`Litter` = 5): the tree foliage
  material can change with the seasons without touching them.
- **New species**: wood blewit and yellowfoot (late autumn and winter),
  St George's mushroom (spring rings in clearings and ride edges), and the
  dangerous lookalikes of the starting species (see M4).
- **Debug**: HUD line *Foliage … Snow … frost … dryness*; `sh.Season.Status`;
  `sh.Season.PreviewMonth 10.8` shows the foliage of any month (0 = off);
  `sh.Weather.Force Snow 6`.

Surface ids of the placeholder vegetation (UV channel 1, `U = (Id + 0.5) / 8`):
Bark 0, Wood 1, **Foliage 2**, Frond 3, Cane 4, Litter 5.

## Step 1 — Snow particles `NS_Snow`

1. In `Content/ShroomHunt/Environment`, right-click `NS_Rain` > **Duplicate**,
   name `NS_Snow`, open it.
2. **Parameters** > **User Exposed** > **+** > *Float* `SnowIntensity`,
   value `1`.
3. Delete the emitters `Drips`, `SplashDrops` and `Splash` (right-click >
   **Delete**): only `Rain` stays. Rename it `Snow`.
4. Select `Snow`:
   - *Emitter Update > Spawn Rate*: Multiply **A** `1500`, **B**: arrow >
     *Link Inputs > User > SnowIntensity*;
   - *Particle Spawn > Initialize Particle*: **Lifetime** `7`, **Sprite Size**
     *Uniform* `1.2` (or X `1.2`, Y `1.2`), **Color** white with alpha `0.9`;
   - *Shape Location*: **Box Size** (2400, 2400, 100);
   - *Add Velocity* > the Add Vector **B**: (0, 0, -150) (flakes fall slowly;
     **A** stays *User.Wind*);
   - *Particle Update* > **+** > **Curl Noise Force**: **Noise Strength**
     `60`, **Noise Frequency** `0.02` (the flakes flutter);
   - *Render > Sprite Renderer*: **Alignment** *Unaligned*, **Facing Mode**
     *Face Camera*; **Material**: keep `M_RainDrop` (its round gradient makes
     soft dots once the sprite is square).
5. **Compile**, **Save**.
6. Open `BP_EnvironmentDirector` > component **SnowParticles** > **Niagara
   System Asset**: `NS_Snow`. **Compile**, **Save**.
   (Class defaults > *Seasons*: **Season Parameters** is already `MPC_Season`.)

## Step 2 — Seasonal foliage on the placeholder trees (`M_Vegetation`)

All trees turn with the **forest average** for now (per genus later).

1. Open `Content/ShroomHunt/Environment/Vegetation/M_Vegetation`. Result node >
   **Details**: **Blend Mode** *Masked* (Nanite supports masked materials; the
   bare winter trees need holes).
2. **Foliage mask** (1 on living leaves only):
   **TextureCoordinate** (**Coordinate Index** `1`) > **Component Mask** (R) >
   **Multiply** by `8` > **Subtract** `2.5` > **Abs** > **Multiply** by `2` >
   **One Minus** > **Saturate**. Call it *FoliageMask* (right-click the last
   node > **Create Named Reroute Declaration**, name `FoliageMask`).
3. **Color**: add **Collection Parameter** nodes (Collection `MPC_Season`):
   `FoliageColor`, `Coloring`, `Freshness`. **Max** (`Coloring`, `Freshness`)
   = the blend amount. **Lerp**: **A** = the existing base color (the
   vertex color chain), **B** = `FoliageColor` (RGB), **Alpha** = blend amount
   × `FoliageMask` (a **Multiply**). Wire the Lerp where the vertex color went
   (into *MF_Wetness* if the base color goes through it).
4. **Leaf fall**: **Collection Parameter** `LeafAmount`. Add a **Vertex
   Color** node and take its **A** pin (alpha = a random value per leaf, 0–1,
   D-039). **Subtract** (`LeafAmount` − *A*) > **Add** `0.5` → *Fall*: the
   leaves drop one by one in a random order. **Lerp**: **A** `1`, **B** *Fall*, **Alpha**
   `FoliageMask`. Wire it into **Opacity Mask** (result node, or the *Substrate
   Shading Models* node if the pin is there). **Opacity Mask Clip Value** stays
   `0.3333` or `0.5`.
5. **Apply**, **Save** (shaders compile: wait).

## Step 3 — Snow, frost on the ground (`M_Landscape_Forest`)

1. Open `Content/ShroomHunt/Environment/Landscape/M_Landscape_Forest`. Find
   where the final base color and roughness leave `MF_Wetness`.
2. **Snow mask**: **VertexNormalWS** > **Component Mask** (B) > **Subtract**
   `0.6` > **Multiply** `4` > **Saturate** (no snow on steep banks) >
   **Multiply** by **Collection Parameter** `MPC_Season.SnowCover`.
3. **Base color**: **Lerp** **A** = wetness output color, **B** = constant
   color (0.85, 0.88, 0.92), **Alpha** = snow mask. Then a second **Lerp** **A** =
   that, **B** = (0.72, 0.78, 0.84), **Alpha** = `MPC_Season.Frost` × `0.3`.
4. **Roughness**: **Lerp** **A** = wetness roughness, **B** `0.65`, **Alpha** =
   snow mask.
5. Wire both into the result node instead of the wetness outputs. **Apply**,
   **Save**.

## UE concepts learned
- **Material Parameter Collections** created from Python
  (`MaterialParameterCollection`, `CollectionScalarParameter`): parameters are
  referenced by id, so the script only adds missing ones.
- **Masked** Nanite materials and dithered opacity for leaf fall.
- **Console variables** (`TAutoConsoleVariable`) for debug previews.
