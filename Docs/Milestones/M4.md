# M4 — Save & content (first part)

Code written ahead (2026-11-23, branch `feat/night-groundwork`). Nothing to
build in the editor. Still to come in M4: more species (morels need a
honeycomb cap in the mesh builder; oyster mushrooms and velvet shanks grow on
wood) and more landmarks.

## What the code provides

- **Save game** (`Save/`, D-037): `UShroomSaveGame`, version 1, one slot
  `Autosave` in `Saved/SaveGames/` (not in the repository). Only what the
  player changed (D-004): game time, weather overrides (part of the rain
  history), player position (same map only), basket, picked mushrooms and
  pick times per patch, knowledge, money, reputation, ban, owned items.
  Forests, patches, weather, shapes are recomputed.
- **When**: autoload when the first game world starts (Play in the editor
  too), autosave at every new game day and when the world closes (Stop,
  quit). Settings: *Project Settings > ShroomHunt > Save* (slot name,
  autoload, autosave each day, save on quit).
- **Debug**: `sh.Save.Now`, `sh.Save.Load`, `sh.Save.Delete`,
  `sh.Save.Status` (optional slot name argument).
- **Content**: 11 species (was 3), with the classic confusions:
  | Edible (starting knowledge) | Dangerous double |
  |---|---|
  | Cep | Bitter bolete (inedible, spoils a dish) |
  | Chanterelle | False chanterelle (stomach upsets) |
  | Green-cracking brittlegill | **Death cap** (deadly) |
  | (Blusher, not in the game yet) | Panther cap (toxic), next to the fly agaric |
  plus wood blewit, yellowfoot (winter) and St George's mushroom (spring).
  Each lookalike lists its key differences in the encyclopedia.

> **New game while testing**: the autosave brings back the last session at
> each Play. For a clean start: `sh.Save.Delete`, then Stop: Stop saves again
> (*Save On Quit*), so either untick *Save On Quit* first, or delete the file
> `Saved/SaveGames/Autosave.sav` with the editor closed.

## Test checklist

- [ ] Play, walk somewhere, pick 3 mushrooms, buy a guide, force rain
      (`sh.Weather.Force Rain 3`), note the time (HUD). Stop.
      Output Log: `Save: saved slot Autosave`.
- [ ] Play again: `Save: loaded slot Autosave` and `player put back at …`; you
      stand where you stopped, same time, same basket and money, the guide is
      owned, the picked mushrooms do not grow back, it still rains (forced
      weather restored).
- [ ] Let a game day pass (`sh.Time.SkipDays 1`): `Save: saved` in the log.
- [ ] `sh.Save.Status` says the slot exists; untick *Autoload* in Project
      Settings: Play starts a new game (the file stays).
- [ ] Automation: `ShroomHunt.Save.*` green.

## UE concepts learned
- **`USaveGame`** and `UGameplayStatics::SaveGameToSlot / LoadGameFromSlot`
  (every `UPROPERTY` is written; `SaveGameToMemory` for the tests).
- **World delegates** (`FWorldDelegates::OnWorldInitializedActors`,
  `OnWorldCleanup`) to act when a map starts or closes.
- **Core ticker** (`FTSTicker`) to wait a few frames for the player pawn.
